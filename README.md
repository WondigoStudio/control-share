# Control Share - публичные ссылки на мониторы

Третий сервис рядом с Control и App Hub. Вы создаёте ссылку на **один монитор**, отправляете её кому угодно, и человек видит страницу статуса: работает ли сервис, доступность за 24 часа и 7 дней, график времени ответа, карту за 90 дней и сбои за 30 дней. Без пароля и без регистрации, но только для чтения.

```
посетитель --> Control Share (этот сервис) --Bearer-токен, только GET--> Control --> Postgres (Neon)
                     |
                     +--> своя таблица share_links (ссылки, счётчик просмотров)
```

Почему отдельный сервис, а не часть Control: пароль и сессии Control не трогаются, публичный трафик не нагружает сам мониторинг (все данные кэшируются), а доступ к Control у этого сервиса такой же узкий, как у App Hub: только чтение разрешённых адресов. Токен Control не даёт читать `/api/config` (там токены ботов и deploy hook'и), поэтому через Share их достать невозможно.

## Что умеет

- Ссылка на один монитор, адрес вида `https://ваш-сервис.onrender.com/s/<случайный токен из 32 символов>`.
- Для каждой ссылки три переключателя «скрыть»: адрес сайта, тексты ошибок и диагностику, автоперезапуск и деплой. **По умолчанию скрыто всё**; больше показывать можно только явным выбором и менять в любой момент.
- Необязательное название на странице вместо имени монитора.
- Отзыв ссылки одним кликом (и восстановление). Удаление навсегда.
- Счётчик просмотров и время последнего. Не считаются: предпросмотры в Telegram и других мессенджерах, поисковые роботы, обновления страницы тем же человеком в течение 30 минут и вы сами, пока вошли в админку.
- Страница сама обновляется раз в 30 секунд, работает на телефоне.
- Если Control спит или недоступен, посетитель видит последние известные данные с пометкой, а не ошибку.

## Установка на Render

1. Положите папку в новый репозиторий GitHub (например `control-share`).
2. На render.com: **New → Web Service**, выберите репозиторий. Render подхватит `render.yaml` (Node, `npm install --omit=dev`, `npm start`).
3. В **Environment** задайте четыре переменные:

| Переменная | Что указать |
|---|---|
| `CONTROL_URL` | адрес вашего Control, например `https://control-to5w.onrender.com` |
| `CONTROL_API_TOKEN` | значение `CONTROL_API_TOKEN` из настроек Control (то же, что в App Hub) |
| `DATABASE_URL` | строка подключения Postgres. Можно **ту же базу Neon, что у Control**: сервис создаёт только таблицу `share_links` и не трогает остальное |
| `ADMIN_PASSWORD` | пароль страницы `/admin`, минимум 10 символов |

   Необязательные: `PUBLIC_BASE_URL` (адрес сервиса для ссылок в админке, если нужен свой домен), `SESSION_SECRET` (секрет подписи входа; иначе берётся из пароля).
4. Дождитесь деплоя и откройте `https://<сервис>.onrender.com/admin`. Войдите, выберите монитор, нажмите «Создать ссылку»: она сразу скопируется в буфер обмена.

Изменений в самом Control **не нужно**.

### Бесплатный тариф Render засыпает

Через ~15 минут без запросов сервис засыпает, первый посетитель ждёт до минуты (страница объяснит это сама и обновится). Чтобы этого не было, добавьте в Control обычный монитор на `https://<сервис>.onrender.com/healthz`: Control будет опрашивать его раз в минуту, и сервис не уснёт. Заодно вы увидите, если сам Share упал.

## Безопасность

- Ссылка работает как секретный адрес: кто её знает, тот видит страницу. Это не вход по паролю. Если ссылка попала не к тем людям, нажмите «Отозвать»: она перестанет открываться сразу, посетители увидят «ссылка недействительна».
- Токен ссылки случайный (192 бита), перебором не подобрать; на частые запросы стоит ограничение. Страницы закрыты от поисковиков (`noindex`, `robots.txt`).
- Данные для страницы собираются по белому списку полей: адрес, тексты ошибок, подсказки «что делать админу», хостинг, токены ботов, deploy hook и данные восстановления наружу не попадают, пока вы явно не разрешили показ адреса или ошибок. Подсказки для админа, токены и deploy hook не показываются никогда.
- Админка: вход по паролю, подписанная кука `HttpOnly; Secure; SameSite=Strict`, проверка Origin, ограничение попыток входа (10 за 15 минут). Если `ADMIN_PASSWORD` не задан, сервис не запустится.
- На страницах нет сторонних скриптов, шрифтов и счётчиков, строгая политика CSP (скрипты только свои).
- Ссылка хранится в базе открытым текстом (чтобы вы могли скопировать её позже). Доступ к базе = доступ к ссылкам, так что не публикуйте `DATABASE_URL`.

## Локальный запуск и тесты

    npm install
    npm test                 # 17 проверок: заглушка Control и Postgres в памяти, ничего не нужно настраивать
    node test/dev.js         # демо с заглушкой на случайном порту, пароль выведется в консоль

Для запуска против настоящего Control создайте `.env` по образцу `.env.example` и выполните `npm start` (для http без TLS добавьте `COOKIE_SECURE=false` и `PGSSL=disable`).

## Устройство

    server.js    запуск, переменные окружения, подключение к БД
    app.js       маршруты: публичные /s/<токен>, /api/s/<токен>, админка /admin и /api/admin
    sanitize.js  белый список полей, единственное место, через которое данные попадают на страницу
    control.js   клиент Control: только GET, кэш, объединение одинаковых запросов, устаревшие данные при сбое
    db.js        таблица share_links
    limits.js    ограничение частоты запросов
    views/ public/   страницы и их скрипты (без сторонних зависимостей)
